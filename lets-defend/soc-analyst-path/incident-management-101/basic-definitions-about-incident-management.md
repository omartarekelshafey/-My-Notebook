# Basic Definitions About Incident Management

## Alert

An Alert is a notification generated by a SIEM system after collecting, parsing, and processing security data. Once triggered, it is forwarded to the Incident Management System for analysis.

## Event

An Event refers to any observable occurrence within a system or network. Examples include a user connecting to a file share, a server receiving a web page request, or a firewall blocking a connection attempt.

## Incident

An Incident is defined as a violation or imminent threat of violation of computer security policies, acceptable use policies, or standard security practices (according to NIST SP 800-61).

**True Positive**

A True Positive occurs when an alert correctly triggers for an actual security threat. For example, a rule detects a real SQL Injection attack being executed via a malicious URL request.

**False Positive**

A False Positive is a false alarm where an alert triggers, but no actual threat exists. For example, a security rule triggers a SQL Injection alarm simply because the word "Union" is found in a URL searching for the sports team "FC Union Berlin".

## Classification Matrix

Based on the provided matrix, here is how the four main detection states break down:

* A True Positive situation occurs when there is an actual cyber attack and the alarm activates, resulting in saving your server.
* A False Positive situation occurs when there is no cyber attack but the alarm activates, resulting in unnecessary tension without losing data.
* A False Negative situation occurs when a cyber attack happens but the alarm does not activate, resulting in data loss.
* A True Negative situation occurs when there is no cyber attack and the alarm does not activate, meaning everything is running perfectly.
